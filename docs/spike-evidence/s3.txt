## Transcribe (lấy timestamp từng từ cho caption)
- Parakeet (`hyperframes models install parakeet`: 639 MB, 198 s): `hyperframes transcribe --engine parakeet --language vi` → exit 1, báo "Parakeet does not transcribe --language vi … Use --engine whisper". **Không dùng được.**
- whisper.cpp qua hyperframes: `--no-runtime-install` → `whisper_unavailable`. Nếu cho phép tự cài runtime thì nó dùng Homebrew hoặc git+cmake, không hợp với máy MKT.
- **faster-whisper 1.2.1** (wheel dựng sẵn, cài 16 s), audio decode bằng ffmpeg-static. Kết quả trên bản Ngọc Huyền:
  | Model | Nạp | Chạy | Khớp từ so với kịch bản |
  |---|---|---|---|
  | small | 2.4 s | 11.9 s | 87.1 % |
  | large-v3-turbo | 4.8 s | 35.2 s | 92.5 % |
  Lỗi tập trung ở tên riêng (SIPOS → "sifos/xefeos", sipos.vn → "seapost vn", ERP → "i2p"). Caption hiển thị **văn bản gốc** (§8.4), ASR chỉ dùng để lấy timing, nên lỗi chính tả của ASR không lên màn hình. M1 cần map văn bản gốc vào timing ASR (sequence match, giống script asr_check.py).
- Độ lệch timing (large-v3-turbo), so với ranh giới khoảng lặng của `ffmpeg silencedetect` (−35 dB, ≥0.25 s):
  - Đầu câu: lệch tuyệt đối trung vị ~95 ms (4–158 ms), có 1 điểm ngoại lai 497 ms.
  - Cuối câu: trung vị ~44 ms (14–82 ms).
  - Bản small có trung vị tương tự, ngoại lai 537 ms.
  - Đánh giá: phần lớn ≤100 ms, nhưng chưa đạt chắc tiêu chí §14.3 "≤100 ms". Bản thân silencedetect cũng không chính xác với phụ âm nhẹ. Cần kiểm thêm bằng tai ở M1, hoặc dùng forced alignment.
- `hyperframes transcribe in.json` import file `[{text,start,end}]` → exit 0, `"format":"words-json","wordCount":96`. File mẫu: docs/spike-evidence/s3-transcript-large-v3-turbo.json.
